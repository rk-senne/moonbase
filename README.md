# 🌙 Moonbase

**K.N.D. Tactical Operations Terminal**

A command-center TUI for orchestrating AI agents across any backend. Built with Go + Bubbletea.

```
moonbase              # launch command center
moonbase deploy 4     # deploy Numbuh 4 (QA) with your default AI
moonbase mission      # run the full KND Council pipeline
```

---

## What It Does

- **Manage** 12 AI operatives with distinct roles and personalities
- **Deploy** them through any AI tool (Kiro, Codex, OpenAI, Anthropic, Ollama)
- **Orchestrate** multi-phase development pipelines
- **Visualize** mission progress, risk gates, and agent handoffs

## Stack

- Go 1.22+
- Bubbletea (TUI framework)
- Lipgloss (styling)
- Bubbles (components)
