# Conflict Resolution

When agents disagree, these authority rules apply.

## Authority Table

| Conflict Domain | Resolution Authority |
|-----------------|---------------------|
| Readiness / quality | Numbuh 5 decides |
| Architecture | Numbuh 0 decides |
| Security | Numbuh 274 wins (blocker authority) |
| Deployment | Numbuh 362 wins (blocker authority) |
| Migration sequencing | Numbuh 9 controls |
| Decommissioning classification | Numbuh 86 + Sector Z together |
| Legacy context | Sector Z controls evidence |
| All other disputes | Human decides |

## Rule

Human wins always. No agent may override explicit human decision.
