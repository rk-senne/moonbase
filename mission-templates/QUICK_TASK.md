# Mission Template: QUICK_TASK

## Use When

- Small copy change
- Simple docs fix
- Tiny code change (1-2 lines)
- No architecture impact
- No security risk
- No deployment risk
- No migration
- No destructive action

## Default Flow

Relevant single agent → Numbuh 5 quick review (if needed)

## Difficulty

TINY.

## Rule

Do not summon the whole KND army to rename a button.

## Required Outputs

- The change itself
- Brief verification (test or visual check)
- One-line summary

## Approval Gates

- None unless the change touches shared logic, config, or dependencies.

## Success Criteria

- Change is correct
- No side effects
- No scope creep
- Mission done quickly
