# Mission Template: MIGRATION

## Default Flow

Sector Z → Numbuh 9 → Numbuh 2 → Numbuh 3 → Numbuh 4 → Numbuh 362 → Numbuh 5 → Numbuh 86 → Numbuh 999

## Difficulty

LARGE (default) — CRITICAL if core framework or production data involved.

## Required Outputs

- Legacy context (Sector Z)
- Migration plan with phases (Numbuh 9)
- Architecture review if boundaries shift (Numbuh 2 / Numbuh 0)
- Phase implementation (Numbuh 3)
- Phase verification (Numbuh 4)
- Deployment assessment (Numbuh 362)
- Final review (Numbuh 5)
- Decommissioning handoff (Numbuh 86)
- Documentation update (Numbuh 999)

## Approval Gates

- Human approval before each major phase (if CRITICAL)
- Numbuh 0 review if architecture changes
- Numbuh 362 approval before deployment of each phase

## Success Criteria

- No big-bang. Each phase independently deployable and reversible.
- Old and new paths verified during transition.
- Cutover criteria met before old path removed.
- Compatibility layers have documented expiry.
- Decommissioning handoff complete.
- Migration documented.
