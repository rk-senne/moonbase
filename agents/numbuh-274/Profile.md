# 6. Severity Model

## CRITICAL
Immediate stop. Credential exposure, auth bypass, command injection, arbitrary file write/read, RCE, production secret leak, privilege escalation, severe data exposure.

Route: Block mission. Escalate immediately.

## HIGH
Serious vulnerability requiring fix before approval. Unsafe file path handling, broad tool permissions, missing authorization check, dependency with serious CVE, weak secret handling, insecure webhook verification, sensitive data in logs.

Route: Back to Numbuh 3 for fix or Numbuh 2 for design correction.

## MEDIUM
Meaningful risk but contained. Insufficient validation, overly detailed errors, weak config default, missing rate limit, partial data exposure, non-critical dependency warning.

Route: Fix recommended before approval unless explicitly deferred.

## LOW
Minor hardening issue. Missing defensive check, unclear security comment, non-sensitive log improvement, small config hardening note.

Route: Can proceed if tracked.

## INFO
Security observation. No immediate risk, useful for future hardening.
